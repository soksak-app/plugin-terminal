# 터미널 plugin 인수 기준

[English](acceptance.md)

이 plugin은 터미널 그림 영역의 이 기준을 담는다. core는 [표면 합성](https://github.com/soksak-app/core/blob/main/docs/spec/surface-composition.ko.md#인수-기준)의 일반 기준을 유지한다.

- 터미널 그림은 리사이즈 중 논리 텍스트를 보존한다. 폭을 줄이면 열 수를 줄여 긴 논리 행을 여러 화면 행으로 재배치하고, 폭을 늘리면 열 수를 늘려 잘림이나 좁은 상태의 영구 고착 없이 다시 재배치한다.
- 터미널 셀 너비와 높이는 배치 중에도 고정된 표시 메트릭이다. 디바이더 이동은 표면·래스터 기하만 바꾸고 글꼴이나 셀 메트릭을 바꾸지 않으며, 네이티브 기하 변경은 애니메이션하지 않는다.

- terminal view의 primary pointer 누름은 shared exposure binder를 통해 선언된 `terminal.focus` command를 실행한다. command는 native image region으로 keyboard 소유권을 넘긴다. view는 기본 DOM focus를 막고, focus 실패를 `terminal.session`과 surface 오류 경로로 보고하며, page를 dispose할 때 binding을 제거한다. 별도 view document는 main document의 card로 pointer가 bubble되는 데 의존하지 않는다.
- native insert는 같은 input-document update의 결과 preedit snapshot을 함께 전달한다. Snapshot은 `text`, `markedRange`, `selectedRange`, `replacementRange`, `attributed`가 있는 완전한 compose object이며 preedit이 남지 않아도 필요하다. 남지 않은 상태는 빈 `text`와 명시적인 range 및 flag로 표현한다. Terminal은 snapshot으로 `terminal.compose`를 갱신하고 확정 text와 compose state를 하나의 `input` request로 보낸다. Region event 순서대로 snapshot을 검증하고 status를 갱신하며 request를 동기적으로 queue하므로 이후 key event가 input을 먼저 queue할 수 없다. VT sidecar는 확정 bytes를 쓰기 전에 compose를 적용한다. 따라서 partial commit 중 PTY echo와 화면 표시가 겹쳐도 확정 prefix와 남은 preedit을 각각 한 번 표시한다. Terminal은 text만으로 compose 전환을 추측하거나 다음 callback을 기다리지 않는다.
- native compose event에는 필수 `markedRange` key가 있다. 표시된 text가 없으면 `null`, 있으면 전체 `text`에 상대적인 UTF-16 code unit 기준 `{location, length}`다. Terminal은 이를 `selectedRange`나 `replacementRange`에서 추론하지 않는다. 정확한 값을 `terminal.compose`와 VT compose input에 보존하며, 누락·잘못된 형식·text 범위 밖·grapheme을 나누는 값은 status 변경이나 input queue 전에 거부한다. VT screen preedit에도 같은 필수 field와 검증을 적용한다. `selectedRange`는 selection과 caret을 계속 별도로 표현한다.
- `terminal.cursor.frame`은 필수이며 nullable이다. 검증된 `screen` event에서 cursor status는 정확한 `frame`(`null` 또는 `{generation, raster, sequence}`)을 해당 event의 cursor와 `cursor.preedit`에 함께 한 번의 status update로 발행한다. Cursor를 갱신하는 `state` event는 rendered screen pixel을 식별하지 않으므로 `frame`을 `null`로 지운다. State cursor의 `frame`은 생략하거나 `null`이어야 하고, non-null screen frame을 지정할 수 없다. 잘못된 frame은 기존 screen-input 오류 경로를 사용하며 이전 cursor status를 유지한다.
- 각 현재 `screen` message에는 `cursor.caret` key가 필요하다. 현재 target의 raster가 수락되지 않았으면(이미지 없음, sequence 0, dirty/future target 포함) 값은 `null`이고, clean sent frame이면 `{row, col}`이다. 0 이상 정수 좌표는 화면 격자에서 보이는 input-method caret을 식별하며 해당 frame과 같은 `RenderLayout`에서 나온다. 원본 `cursor.row`와 `cursor.col`은 engine 및 replay/hash 의미를 유지하고 terminal은 이를 `caret` 대신 사용하지 않는다. Terminal은 같은 screen event의 cursor, frame, render metadata와 함께 `terminal.cursor.caret`을 발행한다. `state` event는 caret을 `null`로 지우며 native caret을 이동하지 않는다. Key 누락, 잘못된 object 형식, 격자 밖 non-null 좌표는 screen 또는 cursor status를 바꾸기 전에 해당 screen event를 거부한다. Null caret은 native caret을 이동하지 않는다.
- 각 현재 screen event에는 `screen.render`가 필수다. `null`은 renderer가 해당 event와 일치하는 draw를 만들지 않았다는 뜻이며, non-null renderer object는 screen event의 frame과 정확히 일치해야 한다. 필수 field는 `frame`, `pixel`, `grid`, `font`, `underline`, `cursor`, `glyphs`다. `pixel`은 top-left BGRA8 premultiplied sRGB raster의 크기와 stride를 식별한다. `grid`는 integer rows, columns, origin, cell 크기를 식별하고 `font`는 실제 family와 metric을 담는다. `underline.positionFromBaseline`은 CoreText y-up 단위를 사용한다. 각 glyph는 row, column, cell width, 양수 CoreText `fontRuns`, grapheme, effective opaque lowercase sRGB foreground/background, nullable fractional top-left leading-cell-local ink/underline rectangle을 담는다. 이 rect는 leading cell origin을 뺀 raw CTFont/CTLine bounds이며 cell에 clip한 geometry가 아니다. x/y는 음수일 수 있고 cell 또는 glyph span보다 bounds가 더 클 수 있다. 좌표는 finite여야 하고 rectangle width/height는 양수여야 한다. Consumer는 pixel 측정 시 geometry와 raster 교집합을 계산할 수 있지만 선언된 bounds를 다시 쓰면 안 된다. Cursor는 `visible`과 `blinkVisible`이 true이고 shape가 `hidden`이 아닐 때만 그려지며, rectangle은 그 frame에서만 non-null이다. 그려지는 normal cursor에는 effective opaque lowercase sRGB color가 있고, difference-blended cursor의 color는 null이다. 그려지지 않는 cursor는 rectangle과 color가 null이며, blink가 꺼진 visible normal cursor도 여기에 포함된다. Terminal은 `frame`, cursor, preedit과 함께 필수 nullable `terminal.cursor.render`를 한 번의 status update로 발행한다. 누락된 field, 잘못된 값 또는 frame mismatch는 screen/cursor 상태를 변경하기 전에 거부한다. Terminal은 terminal 전용 `render` 확장을 제외한 선언된 screen-message projection을 `screenFromMessage`와 `screenHash`에 전달한다. `state` event는 rendered draw를 지정할 수 없다. Cursor를 갱신하면 `frame`과 `render`를 모두 `null`로 지우고 non-null render를 거부한다.
