# Core compatibility

[한국어](core-compatibility.ko.md)

The terminal package uses the view manifest contract of core release `0.0.24`. Its `plugin.json` declares `surface.composition.kind: "view"` without `surface.module`, which the published core `v0.0.20` reader requires. `package.json` declares `engines.soksak: "^0.0.51"`, which admits core 0.0.51 and every later 0.0 release ([versions and ranges](https://github.com/soksak-app/core/blob/main/docs/spec/installation.md#versions-and-ranges)). 0.0.40 is the version of the core release of F502-13 (F502-13-1), the first core release that accepts `exposes.element`, which `plugin.json` declares; core 0.0.39 and earlier accept only the exposes kinds `status`, `commands` and `dom`, so they refuse it. The page uses no plugin API release of its own: the application resolves `@soksak/plugin-api` and its subpaths through the import map of the page, and `engines.soksak` is the only relation of the page to core. The devDependency `@soksak/plugin-api` pins the published plugin API release of core 0.0.47, the lowest core that `engines.soksak` admits, and serves only the manifest check: `make check-manifest` reads `plugin.json`, `diagnostics.json` and the files of `package.json` with its readers, as the installer of core reads them. The page tests resolve those specifiers to fixture modules of this repository (`test/fixtures/plugin-api/`), which record the calls of the page on the plugin API and answer as each test arranges; the tests import the page modules of `ui/` and no core contract case. Core release `0.0.41` is the first core release that carries core F518, which takes the PNG of a view clipboard call through the binary path, and core F617, which gives the answer of a sidecar the cids of its request; the view clipboard and the held input of the view read both.

`make check` runs `make check-manifest` and the event source check and the document check of the kit that `package.json` pins. The registry check compares the exposed names of the release with the declarations of each listed core.
