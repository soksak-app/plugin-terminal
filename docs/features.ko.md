- [o] P4 — P1: 터미널 padding을 변마다 정한다(2026-10-03 사용자 요청). 설정 `padding.top`, `padding.right`, `padding.bottom`, `padding.left`는 0에서 64까지의 정수(pt)이며 기본값은 0이다. 그림 영역과 그에 따른 셀 격자는 padding 안쪽을 차지하고, padding은 터미널 바탕색을 보이며, 스크롤바는 영역의 오른쪽 가장자리에 머물고, 바꾸면 바로 적용된다. Red: 플러그인 test `padding settings inset the region on each side and show the terminal background`가 안쪽 배치 없이 실패했다. core 표면 합성이 네이티브 anchor의 조상에 배경을 금지하므로 padding은 선언된 overlay 띠 네 개다. Green: `make test`가 118개 test로 통과하고, core window check가 두 host에서 통과한다(core G1.4-72).
- [o] P5 — P2: `terminal.scrollbar` DOM 이름을 계약대로 설명한다. 2026-10-03 사용자가 보고한 스크롤바를 관측하다 발견: `plugin.json`은 트랙이 viewport가 최신 출력보다 위에 있는 동안 보인다고 설명하지만, terminal runtime 명세와 `ui/terminal.js`는 터미널이 history를 가진 동안(`scrollback.history`가 0보다 큼) 보인다. 완료: 설명은 터미널이 history를 가진 동안 트랙을 보이고 최신 출력에서 thumb가 맨 아래에 있다고 적는다. 2026-10-03 `make test` 통과.
- [o] P6 — P1: core 체크리스트 항목 G1.4-81을 위해 작업 디렉터리를 카드 발의 하단 글로 알린다. 2026-10-03 완료: 터미널은 시작 디렉터리와 셸이 알리는 각 디렉터리를 `tab.footer`로 알리고, 다른 컴퓨터의 디렉터리는 그 주소를 알린다. 테스트 `the footer shows the start directory and then each directory that the shell reports`는 변경 전 실패했고(Red) 변경 후 통과하며, `make test`가 119개 테스트를 통과하고, core 창 검사 `the content footer shows the footer text that the active tab's plugin reports`가 두 host에서 통과한다.
